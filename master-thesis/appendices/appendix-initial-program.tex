The following program is the complete initial source used to start surface
realization evolution. The code outside the evolution block defines the data
type and the public interface; the marked block is the part that OpenEvolve is
allowed to modify.

\begin{verbatim}
from dataclasses import dataclass

@dataclass
class Triple:
    subject: str
    predicate: str
    object: str

# EVOLVE-BLOCK-START

def predict(triples: list[Triple]) -> str:
    return f"The {triples[0].predicate} of {triples[0].subject} is {triples[0].object}."

# EVOLVE-BLOCK-END
\end{verbatim}
